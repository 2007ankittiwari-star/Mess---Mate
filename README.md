🍽️ VIT Bhopal Mess Control

A web-based Mess Management & Control System designed for VIT Bhopal students and mess administrators.

✨ Features

📋 View mess menu and meal information
🏠 Manage mess-related activities
📊 Track and monitor mess data
👨‍🎓 Student-friendly interface
🔐 Secure and easy-to-use system

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend/Database: Firebase
Hosting: Firebase Hosting
🌐 Live Demo

vit-bhopal---mess-control.web.app

📌 Purpose

The project aims to simplify and digitize mess management at VIT Bhopal, making information and management more accessible to students and administrators.

Made with ❤️ for VIT Bhopal Hostel Students.
